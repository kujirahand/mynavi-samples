# link-checker

指定したWebサイトを起点に、リンクを再帰的にたどってリンク切れを検出するツールです。

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

```bash
python link_checker.py https://example.com --max-depth 3
```

### オプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `start_url` | クロールを開始するURL（必須） | - |
| `--max-depth` | サイト内リンクを再帰的にたどる階層数 | `3` |
| `--min-wait` / `--max-wait` | リクエスト間の待機時間（秒）。この範囲でランダムに待機し、サーバー負荷を抑える | `0.5` / `1.5` |
| `--timeout` | リクエストのタイムアウト秒数 | `10` |
| `--exclude` | チェック対象から除外する拡張子（カンマ区切り） | `.pdf,.jpg,.jpeg,.png,.gif,.zip,.svg,.ico,.mp4,.mp3` |
| `--output` | レポートの出力先ディレクトリ | `results` |
| `--user-agent` | 送信するUser-Agent | `link-checker/1.0` |

## 仕様

- **クロール範囲**: 起点URLと同一ドメイン（サイト内）のページのみ、指定階層まで再帰的にたどります。
- **外部リンク**: 生死チェックのみ行い、そのリンク先のページ内は再帰しません。
- **リンク切れ判定**: HTTPステータスコードが400番台・500番台、またはタイムアウト・接続エラーが発生した場合に「リンク切れ」として記録します（HEADが失敗した場合はGETにフォールバック）。
- **キャッシュ**: 取得したページのHTMLは `cache/` ディレクトリに保存し、`cache/manifest.json` でURLとキャッシュファイルの対応を管理します。同じURLは再取得せずキャッシュを利用します（再実行時の負荷軽減）。キャッシュをクリアしたい場合は `cache/` ディレクトリを削除してください。
- **出力**: 実行結果は `results/` 配下に `CSV` と `JSON` の両方で出力されます。各行は「発見元ページURL / リンク先URL / ステータス（OK・NG）/ ステータスコード / エラー内容」を含みます。
- **集計**: 実行終了時にクロールしたページ数、チェックしたリンク総数、リンク切れ件数がコンソールに表示されます。

## 注意事項

サーバーに負荷をかけないよう、リクエストごとにランダムな待機時間を挟んでいます。大規模なサイトを対象にする場合は `--max-depth` を小さくする、`--min-wait` / `--max-wait` を長めに設定するなど配慮してください。
